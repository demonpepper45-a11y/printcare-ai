# PrintCare AI

基于 RAG 的桌面 FDM 3D 打印机售后问答助手。

## 当前状态

项目规划阶段：已有 Python 工程骨架、环境配置读取和自动检查（T02），尚未实现资料采集、检索、问答与部署，也未验证模型效果。首批拟覆盖拓竹 A1、A1 mini，须先核实官方资料的可访问性和使用条件。

## 第一版目标

- 按机型检索可靠资料，并展示支持答案的原文与链接。
- 对信息不完整的问题追问，对依据不足的问题说明不足。
- 提供逐步排障、多轮上下文和用户反馈。
- 提供简单网页、知识库更新与云端运行方案。

环境准备、测试与静态检查命令见 [开发与接手流程](docs/development.md)。当前尚无问答服务可启动，不要将工程骨架理解为已实现的产品功能。

## 数据与配置

真实密钥、用户对话、运行数据库和未获再分发许可的资料不提交到仓库。代码开源许可待确定；第三方资料的许可另行记录。
