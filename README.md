# PrintCare AI

基于 RAG 的桌面 FDM 3D 打印机售后问答助手。

## 当前状态

项目开发中：已完成官方资料采集与解析、机型过滤检索、基于 DeepSeek 的引用式回答，以及本地 FastAPI 接口与 Streamlit 页面；尚未完成云部署与完整人工评测。首批拟覆盖拓竹 A1、A1 mini，官方资料许可仍待确认。

## 第一版目标

- 按机型检索可靠资料，并展示支持答案的原文与链接。
- 对信息不完整的问题追问，对依据不足的问题说明不足。
- 提供逐步排障、多轮上下文和用户反馈。
- 提供简单网页、知识库更新与云端运行方案。

## 开发入口

1. 阅读 [AI 协作规则](AGENTS.md) 和 [开发与接手流程](docs/development.md)。
2. 阅读 [需求](docs/requirements.md) 和 [架构](docs/architecture.md)。
3. 从 [任务清单](docs/tasks.md) 领取任务，了解 [当前进度](docs/progress.md)。
4. 开发完成后提交代码、验证结果和交接说明。

环境准备、测试与静态检查命令见 [开发与接手流程](docs/development.md)。本地已可启动 API 与页面（需要先入库资料并配置模型 Key）；这不代表答案已通过专业核验。

## 数据与配置

首批官方资料的入口、机型覆盖、解析样例、许可与风险见 [资料来源核实记录](docs/sources.md)。

真实密钥、用户对话、运行数据库和未获再分发许可的资料不提交到仓库。代码开源许可待确定；第三方资料的许可另行记录。
