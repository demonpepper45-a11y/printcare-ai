# 技术决定

以下均为初始草案，待资料与原型验证后确认。

| 决定 | 原因 | 何时重新评估 |
|---|---|---|
| 先覆盖两款机型 | 便于验证机型过滤和专业答案 | 资料范围核实之后 |
| 使用 RAG，先不训练模型 | 便于更新知识和核验依据 | 基线评估显示实际必要时 |
| 第一版采用 Streamlit | 减少初期页面实现成本 | 交互复杂度或使用量增加时 |
| 从一名开发、一名审查开始 | 降低接口与集成协调成本 | 模块接口稳定后 |
| 首先本地验证，再云端试运行 | 先确认资料和问答效果 | 第一版评估完成后 |
| 官方资料只入库元数据与链接，不保存正文副本 | Wiki 未声明许可，站点 `/policies` 禁止抓取，避免再分发风险（T01，Issue #2） | 取得厂商书面许可，或确认可展示的引用范围后 |

正式决定应记录背景、所选方案、替代方案、影响及关联 Issue/PR，不将未经验证的猜测写成结论。
