# 第一版需求

## 用户与范围

面向使用桌面 FDM 打印机的初学者，提供官方资料支持的操作、维护和故障排查建议。拟覆盖 A1 与 A1 mini；资料验证完成后锁定范围。本项目为独立助手，不代表设备厂商。

## 必要功能

1. 机型选择：仅返回适用该机型或明确通用的资料。
2. 知识问答：基于检索材料生成答案，显示来源及相关原文。
3. 追问：缺少影响结论的条件时先询问。
4. 排障：分步骤提供操作和判断条件，保留官方安全前提。
5. 多轮上下文：记录当前机型、现象和已尝试步骤，允许用户更正。
6. 资料不足：明确不足；可提供经核实的官方支持入口。
7. 反馈：记录是否解决和用户自愿填写的反馈。
8. 管理：查看来源、解析状态，新增、更新、禁用资料。

## 资料要求

首批拟整理约 30–50 篇资料，数量服从覆盖需求。记录来源许可及是否允许再分发；官方更新时间未知时明确为空，不能以采集时间代替。

## 验收方法

建立 50 道人工核验的问题，覆盖直接问答、错误码、多段综合、机型冲突、条件不足、无答案及多轮排障。记录预期依据、可接受答案和实际结果，逐类报告，不用单一分数掩盖关键错误。上线阈值在基线评估后由负责人确定。

首版交付需附可运行说明、评估记录、已知限制、部署与备份说明。

## 后续范围

故障图片辅助、更多机型、自动更新提醒和人工支持交接留待基础版本稳定后评估。
